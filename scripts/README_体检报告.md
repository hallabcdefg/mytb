## 二、直连站（24 个）——"点进空分类"根因与修复
### 根因
AppleCMS 站点返回的 `class` 是**扁平列表**（`type_id`+`type_name`，无 `type_pid` 层级字段），
TVBox 会把"电影/电视剧/综艺/动漫"这类**空壳父分类**和"动作片/喜剧片/国产剧"这类**叶子分类**并列展示。
用户点进"电影"→ 请求 `t=1` → 返回 0 条 → 白屏。

### 修复
为 22 个直连站实测扫描全部分类，生成**只含非空分类**的 `categories` 白名单并写入配置。
实测填充率：暴风 98%、建安 95%、茶杯狐/极速/火狐 92%、量子/虎牙 91%…
