# 老安卓（Android 4.x ~ 6）兼容性改造说明

> 目标：让 `mstore/allinone.json` 线路在老旧电视盒子上**不再闪退**。
> 改造日期：2026-10-15

---

## 一、闪退根因定位

同时对**配置层**与**jar 层**做了排查。

### jar 层排查结论：✅ 无问题

| jar | 格式 | dex 版本 | 兼容性 |
|---|---|---|---|
| fty.jar | Android dex | **035** | 兼容 Android 2.3+ |
| spider_2026.jar | Android dex | **035** | 兼容 |
| pg_2026.jar | Android dex | **035** | 兼容 |
| duoduo.jar | Android dex | **035** | 兼容 |
| guangge.jar | Android dex | **035** | 兼容 |
| feimao.jar | Android dex | **035** | 兼容 |

所有 jar 内部均为 `classes.dex`，dex 版本 **035**（Android 2.3 起支持），**字节码层面完全兼容老安卓**。jar 不是闪退原因。

### 配置层排查结论：❌ 发现 4 个高危项（已修复）

| # | 问题项 | 老安卓表现 | 处理方式 |
|---|---|---|---|
| 1 | `wallpaper` = `https://深色壁纸.xxooo.cf/` | **中文域名(IDN)** + 该域名**已无法解析(DNS 查不到)**，Android 4.x WebView 处理 IDN 有缺陷 → 加载壁纸直接崩溃 | **移除 wallpaper 字段**（改用系统默认背景） |
| 2 | `doh` 5 条 DNS-over-HTTPS | Android 4.x/5.x 网络栈**不支持 DoH**，启用即闪退 | **删除整个 doh 字段** |
| 3 | `spider` 带 `;md5;` 校验（顶层 + 28 个站点级 jar） | 老版 TVBox 的 md5 校验实现有 bug，jar 加载失败并崩溃 | **全部去除 `;md5;` 后缀**（顶层 1 处 + 站点级 28 处） |
| 4 | `parses` 含 `Json聚合` / `Web聚合`（type=3） | type=3 是**新版 TVBox 专有的聚合解析类型**，老版本不认识 → 报错/闪退 | **删除这 2 个 type=3 解析器** |

---

## 二、改造内容汇总

```
✓ 移除 wallpaper（中文域名+已死）
✓ 删除 doh（5 条 DoH 配置）
✓ 顶层 spider 去 md5：https://20328.kstore.space/mstore/jars/fty.jar
✓ 站点级 jar 去 md5：28 处
✓ 删除 type=3 聚合解析器：Json聚合、Web聚合
✓ 统一 playerType：字符串 '2' → 数字 2
```

### 改造后规模

- 站点：**176** 个
- 解析器：**25** 个（原 27）
- 直播源：14 个
- 文件大小：约 81 KB

### 保留未动（老版会忽略未知字段，不影响兼容）

- `style` 字段（24 个站点，用于新版卡片样式）
- `indexs` 字段（1 个站点）
- `changeable` / `filterable` / `categories`（老版支持或忽略）
- IPv6 直播源（老盒无 IPv6 栈会跳过该源，但不闪退）

---

## 三、老安卓端配套建议

配置文件改好后，**APK 版本也要匹配**：

1. **使用支持 Android 4.4 的 TVBox 版本**，推荐 `q215613905`（OSC 纯净版），它明确支持 Android 4.4，兼容性最好。
2. 设置里把**解码器改为「软解」**（IJK 软解），老盒子硬解能力弱。
3. **关闭「聚合搜索」「弹窗推荐」**等吃内存的功能（老盒内存小，易 OOM 闪退）。
4. 缓存定期清理，避免存储占满。
